# 1억 가계부 (100Mgoal-app)

광고 없는 개인 가계부 안드로이드 앱 + 홈 화면 위젯.

- 지출·수입 기록, 직접 만드는 카테고리 (저축으로 집계 옵션)
- 고정 지출 등록 → 매달 한 번에 기록
- 생활비 예산, 1억 목표 진행률
- 위젯: 남은 생활비 · 목표 진행률 · `+ 지출` / `+ 수입` 바로 입력 (앱을 열지 않음)

## 설치

1. 폰에서 이 저장소의 **Releases → latest → 100Mgoal.apk** 다운로드
2. 설치 (처음 한 번 "출처를 알 수 없는 앱" 허용)
3. 홈 화면 길게 누르기 → 위젯 → **1억 가계부** 위젯 추가

`main`에 푸시하면 GitHub Actions가 APK를 다시 빌드해 `latest` 릴리스를 교체한다. 같은 서명 키를 쓰므로 덮어 설치해도 데이터가 남는다.

데이터는 폰 안(SharedPreferences)에만 저장된다.
